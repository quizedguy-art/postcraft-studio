## 🛠️ Tech Stack & Zero-Cost Architecture

- **Frontend**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Lucide Icons
- **Export Engine**: `html-to-image` + `jspdf` + `jszip` + `file-saver` (100% client-side GPU accelerated, **\$0 server compute bills**)
- **Storage**: LocalStorage project persistence

## 🚀 Getting Started

### 1. Local Development
```bash
npm install
npm run dev
```

### 2. Production Build
```bash
npm run build
```

### 3. One-Click Free Deployment (Vercel / Netlify / Cloudflare Pages)
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
3. Import the repository and click **Deploy**.
4. Your SaaS is live with a free SSL certificate!
